# 智柜管理系统

基于 RuoYi-Vue、Vue 3、Vite 和 Element Plus 的智能售货机运营管理平台前端。

## 项目背景

本项目面向智能售货机运营场景，用于管理设备、点位、货道、商品、订单、工单、合作商以及运营数据。系统通过运营数据采集和分析，帮助提升补货、巡检、维修和销售管理效率。

## 主要模块

- 首页数据看板
- 设备管理
- 点位管理
- 商品管理
- 订单管理
- 工单管理
- 策略管理
- 合作商管理
- 系统管理、监控和代码生成等 RuoYi 基础能力

## 开发命令

```bash
npm install
npm run dev
npm run build:prod
```

开发服务默认端口为 `81`，接口代理前缀为 `/dev-api`。

## 当前登录模式

项目当前使用本地免登录模式：路由初始化时直接注入 mock 管理员身份，不再请求登录接口，也不会进入登录页。
